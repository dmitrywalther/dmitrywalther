# Dmitry Walther

**Senior Product Analyst at VK · Machine learning & geospatial analytics**

I work at the intersection of product analytics and machine learning. At VK, I take ownership of ML tasks: I work directly with internal stakeholders, handle the full modeling workflow, define requirements for partner teams, and help colleagues apply ML to analytical problems.

My work spans churn prediction, uplift modeling, experimentation, and product measurement. I have automated daily churn scoring for advertising accounts and support experiment evaluation through ML-based matching when there are limitations with the control group.

Geospatial analytics is my main interest for independent projects. I hold an MSc in Cartography and Geoinformatics from Lomonosov Moscow State University and have worked on desktop GIS software using ArcGIS Runtime SDK for Java.
